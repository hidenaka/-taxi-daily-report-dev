深夜に要るのは遅れている便。
朝の便ではない。

そのとおりに直しました。あわせて「その日いつまで客がいたか」も見られます。

何が起きていたか

遅れて日付をまたぐ便は、データに 24:33 のような書き方で入っています。

直したもの① 深夜は「持ち越しの便」を最上部に

22時〜朝5時のあいだ、画面のいちばん上に出ます。

🌙 前日から持ち越しの便（1便）
00:33 7分前に到着 3号 千歳 NH4738 113分遅れ タクシー 81人
朝の便（5便）は今は畳んでいます
朝の便は畳みます。深夜0時台に「4時50分のニューヨーク便」を見せても仕方がないので、件数だけ添えて隠します。
翌日の昼に振り替わった便は入れません。実データに「翌日15:20着（20時間40分遅れ）」という便があり、これを混ぜると画面が使い物にならなくなるので、朝6時までに着く便だけにしています。

直したもの② 過去の日は「その日いつまで客がいたか」

現地の掲示を調べたら、毎日「本日の配車業務は終了しました」が出ていました。その時刻を記録しました。

日終了案内が出た時刻
9/5(土)02:00
9/6(日)00:50
9/7(月)01:14
9/8(火)01:30

日によって1時間半以上ちがいます。「今日は何時まで粘れるか」の目安になります。

過去の日を開くと、こう出ます。

📋 この日のまとめ
配車業務の終了案内01:30
遅れた便15分以上 1便
いちばん遅れた便千歳 NH4738
定刻 22:40 → 00:33（113分遅れ / 3号）
日をまたいだ便1便
00:33 千歳 NH4738（113分遅れ / 3号 / タクシー81人）

これから毎日たまります

到着便の記録毎日 23:55 に、その日ぶんを保存
終了案内の時刻0:10〜3:00 の20分おきに見張って、出た時刻を記録
（掲示は日付が変わってから出るため。時刻は最大20分の幅があります）
残す期間直近7日

まとめ

  • 深夜は前日から遅れている便が最上部に出ます。到着時刻・遅れ・号・タクシー人数つき。
  • 要らない朝の便は畳みます。
  • 過去の日は「何時に配車業務が終わったか」が見られます。日によって00:21〜02:00と幅があります。
  • 遅れた便の数・いちばん遅れた便・日をまたいだ便も出ます。
  • いま dev に入っています。本番にはまだ出していません。
