# 国道の交通量（国土交通省 交通量API）

工事の地図の「国道の交通量」ボタン（丸に棒グラフ）で出す層。23区とそのまわりの国道の観測点の1時間ごとの台数を、7日前の同じ時間と比べて色を付ける。

## データ

- 取り込み: `.github/workflows/sync-jartic.yml`（毎時40分）→ `.github/scripts/sync-jartic.mjs` → `tools/data/jartic-traffic.json`
- 取りに行くのは1回に2件（常設 `t_travospublic_measure_1h` と CCTV `t_travospublic_measure_1h_img`、6時間前〜前の時間、道路種別=3、四角 139.56–139.92 / 35.52–35.82）。間は3秒空ける。データが無いときだけ8日分を1日ずつ取る（16件）
- 値は1〜2時間遅れて入る（2026-10-24 10:11 に 8時台まで）
- 8日分（192時間）を持つ。形は `tools/js/jartic-data.js` の先頭に書いた
- 台数: 常設は小型＋大型＋判別不能。欠測・停電・ループ異常・超音波異常が立った向きは null。CCTV は「自動車交通量」（null は 0 にしない）
- 使わない向き（`off`）: 8日間の昼（7〜21時台）の真ん中の値が 20台/時 未満、または値が無い向き。CCTV は向きごとに別の観測点のことがある
- 道の名前: 観測点から40m以内の `tools/lanes/lanes23.geojson` の名前（目安）。23区の外は空 →「国道（23区の外）」
- 取りに行った記録: `.github/scripts/data/jartic-access-log.tsv`（60日分）

## 規約（交通量API 利用規約 2025-05-12）で守ること

- 第5条: 層を出している間は、地図の上の説明に「このサービスは、交通量API機能を使用していますが、サービスの内容は国土交通省によって保証されたものではありません。」を必ず出す（×を押しても、この文だけは残る）。吹き出しと「この地図について」に出典「国土交通省 交通量API機能による交通量（参考値）を加工して作成」
- 第6条: 短い時間に大量に取りに行かない
- 第8条: 取りに行った記録を残す
- 第3条: 参考値。正式な交通量調査の結果として見せない

## 本番について

本番は `v*` タグのときだけ dev から写される。毎時の更新を本番にも出すには、本番にも送る仕組みが要る（工事の koji.json も同じで、本番は 2026-10-15 のまま）。
